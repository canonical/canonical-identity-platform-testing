# Canonical Identity Platform Test Plane

Test plane for the Canonical Identity Platform (Kratos, Hydra, login-ui, and optional tenant-service, hook-service, user-verification-service). It builds nothing and contains no service checkouts. A run brings up a deployment profile via Docker Compose from published images or store charms on Juju, verifies the deployment matches its declaration, seeds deterministic test data, and runs the Playwright browser suite and Go E2E suite against it.

## Two Lanes

- **The gate**: blocking, per-PR. Three pinned profiles: `core`, `canonical-internal`, `canonical-portal`. `make gate PROFILE=<name>` runs typecheck, brings up the stack, executes smoke checks, runs the browser suite twice, and finishes with Go E2E. Green on all three profiles is the merge condition.
- **The matrix lane**: nightly, non-blocking. Runs three seed rows (`pd931-single-oidc-mt`, `tfdefault-oidc-only`, `deployed-core-local-mfa`) plus five generated rows derived from `matrix/config-model.mjs` across nine dimensions with pairwise coverage. A red row produces a named finding and is never silently skipped.

## Prerequisites

Compose lane requires `go`, `node` (with `npx`), and `docker` with the `compose` plugin. Host ports 80 and 443 must be free for Traefik. Postgres is not published to the host.

Juju lane additionally requires `terraform` and `juju`.

Verify host prerequisites:
```bash
make dev-check
JUJU_LANE=1 make dev-check  # Juju lane only
```

## First Run

Run these commands from the repository root in order:
```bash
make dev-check
make test-browser-setup        # npm install + Playwright Chromium and Chrome channel
make profile-set PROFILE=core  # writes .active-profile
make gate PROFILE=core         # ~10 minutes; ends with "✓ Gate passed: core"
```

## Day-to-Day Commands

Iterate against the active profile:
```bash
make up                        # stack for active profile, blocks until healthy
make seed-test-data-clean      # wipe and re-seed test users and tenants
make test-browser              # browser suite, internal lane
make test-browser-list         # collect only; catches import-time scenario errors
make check                     # hermetic: typecheck, matrix artifacts, unit tests, port audit
make down
```

Run one scenario:
```bash
cd tests/browser && npx playwright test specs/login.spec.ts -g "<scenario-id>"
```

## Rules

- Tests are data: add a `Scenario`, not a Playwright script.
- Suite uses `retries: 0`, one worker, and no flaky or quarantine tags.
- Every skip must name a missing capability.
- The seeder only deletes `@test.example` identities and `iam-test ` tenants.
- The row's declared `capabilities.json` drives gating, and `matrix/verify.mjs` refuses a deployment that does not match it.
- Run `make gate PROFILE=<name>` before claiming a change works.

## Machine-Local State

The following untracked files are ignored by git:
- `.active-profile`: tracks the locally selected profile.
- `tests/browser/manifest.json` and `active-config.json`: generated by seed and global setup.
- `matrix/backends/juju/root/local.auto.tfvars`: Juju lane config, copied from `local.auto.tfvars.example`.
- `*-manifest.json`: out-of-band seed manifests containing credential material.
